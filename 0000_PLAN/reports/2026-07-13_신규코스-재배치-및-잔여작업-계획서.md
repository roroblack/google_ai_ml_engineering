## 3. 구현 설계 (사이트 반영 방법)

> RULE §12: 주차 구조·진행률 무손상. 제목·코스만 조정.

### 3.1 데이터 구조 확장 — `WEEK_CO`(co-course) + `WEEK_FIFTH_COURSE`
- 현재 `WEEK_COURSE[wk]`는 주당 코스 1개. **주당 복수 코스**를 위해 별도 맵 추가(기존 구조 무변경 → 안전):
  - `WEEK_CO = { "14":[539], "16":[927], "17":[989] }` (필수 co-course)
  - `W13` 5회차: 536은 `ALT_RES`/`fifth` 계열에 "선택 선행" 링크로 노출(완료 판정 제외).
- 렌더러 `daySection`/`weekLabsRefSection`/`labRowHTML`에서 primary 코스 아래 **co-course 링크 줄**을 추가 노출. 완료 상태는 courseId별 독립.

### 3.2 W14·W17 제목/번들 정리
- W14 `wk-theme`: "Generative AI 개요 + Model Evaluation" → **"Model Evaluation (+ 선행: Intro to LLM)"** 로 정리(536은 W13으로 이동 반영).
- W17: 985·989를 **별도 두 줄**로 분리 표시(현재 합성 표기 해체).

### 3.3 표시 텍스트 "Vertex AI" → "Agent Platform" (5곳, 표시용만)
검증된 대상 (URL·코드랩 제목·deprecated 안내는 **건드리지 않음**):
1. W13 `wk-theme` `MLOps with Vertex AI: Manage Features` → `MLOps with Agent Platform: Manage Features`
2. W3 `wk-theme` `Working with Notebooks in Vertex AI` → `Working with Notebooks (Agent Platform)` *(삭제 코스명이지만 표기 통일)*
3. W3 `day-focus` 복습 카드 동일 문구
4. W3 `sec-chip` `W-2 · Notebooks in Vertex AI`
5. W3 `wk-meta-v` `코스: Notebooks in Vertex AI`
- ⚠️ 전체 "Vertex AI" 57곳 중 **위 5곳만** 선별. 나머지(랩 원본명, codelab 제목, "구 Vertex AI→" 안내문)는 **의도적 보존**.

### 3.4 시험 정보 확정 반영
